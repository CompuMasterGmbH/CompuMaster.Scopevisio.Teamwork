# CompuMaster.Scopevisio.Teamwork 2026.10.13.0

This release updates the adapter's default dependencies to CompuMaster.CenterDevice.Rest 2026.10.13.0 and CompuMaster.Scopevisio.OpenApi 2026.10.13.0. It covers the complete change set since Teamwork 2026.10.08.0 while retaining the existing public and synchronous APIs, account selection, authorization defaults and three targets: netstandard2.0, net6.0 and net48.

- Standalone consumers receive the reviewed SDK package pair. CenterDevice supplies log4net 3.5.0 transitively. See the SDK releases for their added workflows and compatibility limits.
- The configured build and isolated-test CI matrix is serialized within this repository. Cross-repository and local shared-server access still requires a coordinated exclusive window.
- Publishing checks the release event and agreement between the tag and fixed project version before building or uploading packages.

This dependency adoption does not resolve the selected-comment bridge route limitation (Teamwork #9) or the upstream server-error investigation (Teamwork #10), and does not establish complete SDK API or permission acceptance. The current CI workflow leaves the historical real-server test steps commented out, so a successful configured matrix is not real-server acceptance. DMS adoption and combined verification remain separate in DMS #90.

Release preparation requires verified SDK packages, three adapter builds, isolated authorization/renewal/diagnostic checks, independent review and successful full serialized post-merge CI before publication. Actual CI and publication evidence will be recorded when those prerequisites complete.
