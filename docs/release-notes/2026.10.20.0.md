# CompuMaster.Scopevisio.Teamwork 2026.10.20.0

- Requires CompuMaster.CenterDevice.Rest 2026.10.20.0 so standalone Teamwork consumers receive three concurrent requests per HTTP origin and no fixed minute quota by default.
- Retains shared server overload cooldowns, Retry-After handling, cancellation and no automatic replay of ambiguous writes through the SDK transport.
- Allows applications with a known quota to configure `CenterDeviceHttpTransport.ConfigureRequestRateLimit(Uri, int?)` before the origin's first request. Passing null leaves the fixed minute quota disabled.

Teamwork public signatures, token/session renewal and explicit account/instance selection remain unchanged. The OpenScope dependency remains 2026.10.13.0; DMS separately selects its existing 2026.10.16.0 package. These client defaults are not manufacturer quotas.
